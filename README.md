# ЛЕС / ФОРМА — 3D-конфигуратор дома

Демонстрационный сайт каркасного дома на HTML, CSS, JavaScript и Three.js.

Вращение и масштабирование модели, выбор фасада, крыши, рам и остекления, переключение террасы, условный расчёт стоимости и скачивание комплектации.

Модель и цены демонстрационные. Для локального запуска: `python3 -m http.server 8080`.

Three.js и OrbitControls включены локально; лицензия MIT сохранена в vendor/LICENSE.three.txt.

## Визуализация

Добавлены процедурные фактуры, проёмы окон, детали кровли и окружения. Материалы генерируются локально, без внешних запросов. Отдельный AI-рендер в assets/scandi-concept.png обозначен как концепт и не синхронизируется с выбором комплектации. Он не является фотографией построенного дома.
